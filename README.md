# Mood-Analysis-Framework
The Nyāya Knowledge Validation Framework combines the principles of the Indian Knowledge System (IKS) with modern Computer Science concepts. Each Nyāya Pramāṇa is represented by a corresponding process in the system to validate user-entered statements.
Pratyakṣa (Observation) is represented by checking whether the entered statement exists in the knowledge base. The system directly compares the user's input with the stored statements.
Anumāna (Inference) is represented by the logical validation process. Based on the matched statement, the system determines the appropriate confidence score and verdict (VALID, PARTIALLY VALID, or INVALID).
Upamāna (Comparison) is represented by comparing the user's statement with similar statements stored in the predefined knowledge base to identify the closest match.
Śabda (Authoritative Testimony) is represented by the predefined knowledge base, which acts as a trusted source of information used by the system during validation.
